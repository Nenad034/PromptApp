# Saved Prompts Folder

Ovaj folder je kreiran da bi u njega čuvali sačuvane promptove.

## Kako koristiti

Kada kliknete dugme **"Sačuvaj"** u aplikaciji, prompt će automatski biti preuzet u vaš Downloads folder sa nazivom:

`{naziv-prompta}-{timestamp}.md`

## Preporučeno

Premeštajte sačuvane promptove iz Downloads foldera u ovaj folder da biste ih organizovali na jednom mestu.

## Lokacija

Ovaj folder se nalazi u root direktorijumu aplikacije:
```
PromptApp/
  ├── saved-prompts/     ← Ovde čuvajte promptove
  ├── src/
  ├── public/
  └── ...
```
